# Phase 6 输入链路 - 手动测试清单

> 本清单覆盖 Phase 6 输入链路的所有验证点。每个测试项需在 WT 注入目标进程后逐项验证。
> 测试流程：启动 cmd → 启动 WT → 在 WT 中运行注入命令 → 按清单逐项测试。

---

## 测试环境准备

1. 启动目标 cmd 进程（记录 PID）
2. 启动 WT
3. 在 WT 中运行：
   ```
   C:\Users\rikka\Desktop\terminal-injector\build\bin\Release\terminal_injector.exe --mediator --target-pid <PID>
   ```
4. 确认握手成功（WT 中出现 cmd 提示符，mediator 日志出现 "Handshake OK"）

## 1. cmd 键盘基础

### 1.1 字符输入与回显
- [ ] 输入 `dir` + Enter，执行 dir 命令，显示结果
- [ ] 输入 `echo hello` + Enter，输出 `hello`
- [ ] 输入空行（直接 Enter），回到提示符无报错

### 1.2 退格
- [ ] 输入 `diq`，按退格删除 `q`，剩 `di`，再输入 `r` + Enter 执行 dir
- [ ] 连续退格清空整行，回到纯提示符

### 1.3 方向键

- [ ] 按 Left/Right 在行内移动光标，输入字符在光标处插入
- [ ] 按 Home/End 跳到行首/行末

### 1.4 Tab 补全
- [ ] 输入 `cd Des` + Tab，补全为 `cd Desktop`
- [ ] 连续 Tab 循环下一个匹配
- [ ] Shift+Tab 反向循环

### 1.5 历史导航
- [ ] 执行多条命令后，上箭头依次调出历史
- [ ] 下箭头回到最新
- [ ] 上箭头调出历史后修改，再上箭头不丢失修改

### 1.6 控制字符
- [ ] Ctrl+C 中断当前输入，显示 `^C` 换行（Phase 7 完善信号）
